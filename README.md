# CreditChek Approval React Native & Expo SDK

Official React Native and Expo module for **CreditChek Approval**, providing active face liveness and biometric identity verification directly in your React Native applications with **dynamic backend-driven orchestration**.

Compatible with both **Expo (Development Builds / Prebuild)** and **Bare React Native CLI**.

---

## 🌟 What's New: Dynamic Orchestration & Universal Splash Screen

- **Zero Hardcoded Flows**: Host applications no longer configure `environment` or `modules` in JavaScript. The SDK fetches them dynamically from your widget configuration via **`widgetId`** (`GET /auth/sdk-setup/{widgetId}`).
- **Universal Splash Screen**: A single pulsing splash screen handles credential validation, widget setup loading, and smart step-skipping for already-completed checks.
- **Dynamic Theming & Custom Brand Logo**: The verification flow automatically adopts your brand's primary color and custom logo.

## ⚙️ Configuration & Permissions

### 1. Expo (Managed / Prebuild / EAS Build)

Add the module's Config Plugin to your `app.json` (or `app.config.js`). This automatically configures `NSCameraUsageDescription` on iOS, `android.permission.CAMERA` on Android, and sets `minSdkVersion = 24`:

```json
{
  "expo": {
    "plugins": [
      [
        "approval_react_native",
        {
          "cameraPermission": "Allow CreditChek Approval to access camera for face verification."
        }
      ]
    ]
  }
}
```

> **Note**: Because CreditChek Approval uses native biometric libraries (CameraX, ML Kit, and AVFoundation), testing requires an **Expo Development Build** (`npx expo run:ios` or `npx expo run:android`) or an EAS development build, rather than the Expo Go sandbox.

---

### 2. Bare React Native CLI

#### iOS
1. In your `ios/Podfile`:
   ```ruby
   platform :ios, '15.0'
   ```
2. Install pods:
   ```bash
   npx pod-install ios
   # or
   cd ios && pod install
   ```
3. Add camera permission in `ios/YourApp/Info.plist`:
   ```xml
   <key>NSCameraUsageDescription</key>
   <string>Allow CreditChek Approval to access camera for face verification.</string>
   ```

#### Android
1. In `android/app/build.gradle`:
   ```groovy
   android {
       defaultConfig {
           minSdkVersion 24 // Required for CameraX & ML Kit
       }
   }
   ```
2. Ensure JitPack is included in `android/build.gradle`:
   ```groovy
   allprojects {
       repositories {
           google()
           mavenCentral()
           maven { url 'https://jitpack.io' }
       }
   }
   ```
3. Add camera permission to `android/app/src/main/AndroidManifest.xml`:
   ```xml
   <uses-permission android:name="android.permission.CAMERA" />
   ```

## 🚀 Quick Start

```tsx
import React from 'react';
import { View, Button, Alert } from 'react-native';
import CreditChekApproval, { SessionResult } from 'approval_react_native';

export default function VerificationScreen({
  backendSessionId,
  widgetId,
}: {
  backendSessionId: string;
  widgetId: string;
}) {
  const launchVerification = async () => {
    try {
      const result: SessionResult = await CreditChekApproval.start({
        // Your public API key from CreditChek dashboard
        publicKey: 'pk_test_...',

        // Unique session UUID generated by your backend via /v1/auth/widget-session/create
        sessionId: backendSessionId,

        // Widget configuration ID from CreditChek dashboard
        widgetId: widgetId,

        // Optional prefilled user data
        userData: {
          firstName: 'Jane',
          lastName: 'Doe',
          bvn: '12345678901',
          nin: '12345678901',
          email: 'jane.doe@example.com',
          phone: '+2348012345678',
        },
      });

      switch (result.status) {
        case 'success':
          Alert.alert('Verification Successful', `Session ID: ${result.sessionId}\n${result.message}`);
          break;
        case 'cancelled':
          Alert.alert('Verification Cancelled', 'The user dismissed the flow.');
          break;
        case 'error':
          Alert.alert('Verification Error', `[${result.code}] ${result.message}`);
          break;
      }
    } catch (error: any) {
      Alert.alert('Error', error?.message || 'Could not launch verification');
    }
  };

  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Button title="Verify Identity" onPress={launchVerification} />
    </View>
  );
}
```

## 📚 API Reference

### `CreditChekApproval.start(config: ApprovalConfig): Promise<SessionResult>`

Launches the native full-screen biometric verification widget.

#### `ApprovalConfig`

| Property | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `publicKey` | `string` | **Yes** | Your CreditChek public API key. |
| `sessionId` | `string` | **Yes** | Session ID created by your backend via `/v1/auth/widget-session/create`. |
| `widgetId` | `string` | **Yes** | Widget ID from your dashboard (supplies branding, color, environment, and order). |
| `userData` | `ApprovalUserData` | No | Optional prefilled user information (`bvn`, `nin`, `name`, etc.). |

#### `ApprovalUserData`

| Property | Type | Description |
| :--- | :--- | :--- |
| `firstName` | `string` | User's first name |
| `lastName` | `string` | User's last name |
| `bvn` | `string` | 11-digit Bank Verification Number |
| `nin` | `string` | 11-digit National Identity Number |
| `email` | `string` | User email address |
| `dob` / `dateOfBirth` | `string` | ISO 8601 date of birth (e.g. `2000-10-01`) |
| `phone` | `string` | Phone number with country code (e.g. `+2348012345678`) |

#### `SessionResult`

Union type returning the status of the verification session:

```ts
type SessionResult =
  | { status: 'success'; sessionId: string; message: string }
  | { status: 'cancelled' }
  | { status: 'error'; code: string; message: string };
```
